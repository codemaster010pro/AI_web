# AI Adaptive Learning Platform

An intelligent, interactive learning web application designed to evaluate user knowledge, dynamically generate personalized diagnostic assessments, and provide tailored AI tutoring. 

Built with a **FastAPI** backend leveraging **LangChain/LangGraph** for multi-step AI orchestration and a sleek, responsive **Tailwind CSS + Vanilla JS** frontend.

###  Key Features
* **Adaptive Diagnostic Onboarding:** Dynamically generates assessment questions based on the user's chosen subject and skill level.
* **Interactive Quiz Interface:** Modern option card selection UI with auto-submission and support for custom user notes/context.
* **Personalized AI Tutor Chat:** Full chat interface featuring Markdown rendering, syntax highlighting, and live links for structured study follow-ups.
* **CORS & Cloud-Ready Deployment:** Easily deployable across Render (backend/frontend) or Vercel with complete anti-blocking scraper options for external resources.

###  Tech Stack
* **Frontend:** HTML5, Tailwind CSS, FontAwesome, Marked.js
* **Backend:** Python 3.11+, FastAPI, Uvicorn, Pydantic
* **AI Orchestration:** LangChain / LangGraph, Google Gemini API
